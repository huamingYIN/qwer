# ColorStudio Pro

**专业色彩识别 · 调色 · 配色 · 吸色工具**

面向设计师、平面设计、广告制作、印刷设计、电商设计、UI 设计、宣传品设计及办公人员的专业本地色彩工具。
完全本地运行：**无需服务器、无需数据库、无需登录、无需联网**。

---

## 一、快速开始（最简单）

1. 打开 `ColorStudioPro_单文件版` 文件夹；
2. **双击 `index.html`**，系统会用默认浏览器打开；
3. 立即开始调色、吸色、配色与导出。

> 单文件版已把全部 HTML / CSS / JavaScript 内联到一个文件，断网可用，可随意复制到任何电脑、U盘。

多文件版（`ColorStudioPro` 文件夹）为模块化源码，同样双击其中的 `index.html` 即可运行，方便二次开发。

推荐使用 **Chrome / Edge（Chromium 内核）** 浏览器以获得「屏幕吸色」能力；Firefox、Safari 可正常使用除屏幕吸色外的全部功能（可用图片吸色替代）。

---

## 二、核心功能

### 1. 颜色输入与转换
- 支持输入：**HEX、RGB、RGBA、HSL、HSV(HSB)、CMYK**，自动识别格式并实时转换；
- 自动计算并显示：**HEX / RGB / RGBA / HSL / HSV / HSB / CMYK / LAB / LCH / XYZ**；
- 每项数值旁均有「复制」按钮，复制成功提示「已复制」；
- 输入错误时提示「请输入正确的颜色格式」，不会崩溃。

### 2. 专业调色
- **二维颜色选择器**：横向饱和度、纵向明度，右侧色相彩虹竖条，下方透明度滑条，支持点击与拖动；
- **RGB / RGBA**：数字框 + 滑块，含 Alpha 透明度；
- **HSL / HSV**：数字框 + 滑块实时调色；
- **CMYK**：C/M/Y/K 数字框 + 滑块，实时联动全部色彩空间。

### 3. 吸色
- **图片吸色**：导入 JPG / JPEG / PNG / WEBP / BMP，支持直接把图片**拖入窗口**；
- **专业放大镜**：跟随鼠标，放大显示像素网格、十字准星、当前像素 RGB 与 HEX，点击确认吸取；
- **屏幕吸色**：基于 EyeDropper API，可从屏幕任意位置取色（不支持的浏览器会友好提示）。

### 4. 图片颜色分析
- 自动分析图片 **TOP 5 / TOP 10 / TOP 20** 主要颜色，显示 HEX、RGB 与占比；
- 一张图片可连续吸取多个颜色，自动组成「图片配色方案」，可一键保存为色板。

### 5. 自动配色
- 一键生成 **11 类配色方案**（每类 5 色）：单色、类似色、互补色、分裂互补、三角色、四角色、双互补、暖色、冷色、柔和、高对比；
- 每个色块可点击使用、复制、收藏；
- **60 / 30 / 10 配色预览**：直观模拟网页界面效果；
- **明暗色阶**：自动生成 50–900 共 10 档 UI 色阶。

### 6. 渐变生成器
- 线性 / 径向渐变，支持 2–5 个颜色节点；
- 可调颜色、位置、角度，实时预览并生成可复制的 CSS 代码。

### 7. 对比度与文字建议
- **WCAG 对比度检测**：计算对比度比值，判定普通 / 大号文字的 **AA / AAA** 是否通过；
- 给定背景色自动**推荐黑 / 白文字**并给出对比度；
- 支持前景背景交换。

### 8. 颜色管理
- **历史记录**：自动记录最近 30 / 50 / 100 个颜色，可恢复、单删、清空；
- **收藏夹**：保存颜色、自定义名称、改名、删除；
- **品牌色板**：为「我的品牌 / 项目A / 宣传册 / 海报 / 网页设计」等建立独立色板，支持新建、重命名、删除、加色、删色。

### 9. 导出
- **PNG 色板图**（高清印刷级，含名称、HEX、RGB、CMYK）；
- **SVG** 矢量色板；
- **JSON / CSS / TXT**；
- **GPL**（GIMP / Inkscape）、**ASE**（Adobe Swatch Exchange）；
- **CSS 变量**一键复制；**Tailwind 配置**（primary-50 … primary-900）一键复制；
- 支持**全部数据导出备份 / 导入恢复**。

## 三、快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl + V` | 粘贴颜色代码（焦点不在输入框时） |
| `Ctrl + C` | 复制当前颜色 HEX |
| `Ctrl + S` | 保存当前颜色到收藏 |
| `Delete` | 删除色板库中选中的颜色 |
| `Esc` | 关闭弹窗 / 菜单 |
| `Ctrl + Z` | 撤销（最多 50 步） |
| `Ctrl + Shift + Z` | 重做 |

输入框内支持标准的 `Ctrl + A / C / V`。

---

## 四、数据与隐私

- 所有数据（当前颜色、历史、收藏、品牌色板、设置）仅保存在本机浏览器 **LocalStorage**；
- 软件不发起任何网络请求，不收集、不上传任何数据；
- 可在「设置」中导出全部数据做备份，或导入 JSON 恢复；更换浏览器 / 电脑时迁移即可。
- 若浏览器禁用 LocalStorage，软件仍可在当前会话正常使用（数据不持久化）。

---

## 五、印刷色彩说明

- **RGB 适合屏幕显示，CMYK 适合印刷参考**；
- RGB→CMYK 的数学转换**未绑定具体 ICC 配置文件**。不同显示器、ICC 配置、印刷设备与纸张都会造成实际颜色差异，
  因此 CMYK 数值**仅供参考**，正式印刷请以印刷厂的分色打样为准。

## 六、文件结构（多文件版）

```
ColorStudioPro/
├── index.html    # 页面结构
├── style.css     # 全部样式（浅色 / 深色 / 响应式）
├── color.js      # 颜色科学：HEX/RGB/HSL/HSV/CMYK/XYZ/LAB/LCH、解析、中文命名
├── palette.js    # 配色方案、色阶、WCAG、渐变 CSS
├── picker.js     # EyeDropper、放大镜、图片颜色分析
├── storage.js    # LocalStorage 数据层
├── export.js     # PNG/SVG/JSON/CSS/TXT/GPL/ASE 导出
├── app.js        # 主界面逻辑、撤销重做、快捷键
└── README.md     # 使用说明
```

各模块通过全局命名空间（`ColorMath` / `Palette` / `Picker` / `Store` / `Exporter`）协作，
使用普通 `<script>` 顺序加载，在 `file://` 协议下可直接运行。
